# Network Configuration

Determine the system’s current local network configuration, then create a NEW network connection named **rhcsa-exam** to meet the following requirements:

*   **IPv4 Address:** An IP address within the same network as the current configuration, with a host ID of 50
*   **Netmask:** 255.255.255.0
*   **Default gateway:** Within the same network, with a host ID of 1
*   **DNS server:** 8.8.8.8
*   **DNS search domain:** example.local

Set the system hostname to:
*   `rhel-node1.example.com`

*Note: Because this is a remote browser lab, do NOT activate this connection, otherwise you will lose connection to the terminal. Just save the configuration.*
